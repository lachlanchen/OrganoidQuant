# Set 001 Fusion Report

This folder contains the curated human-readable report for the blinded `set_001` fusion-analysis cohort.

## Files
- `set_001_day_order_report.md`: day-ordered Markdown report with images, values, and justification.
- `assets/`: preview PNGs generated from the private source TIFFs for embedding in the Markdown report.

## Data flow
- The prompt tool saw only blinded UID images.
- The day/date order was reconstructed afterward using the private mapping CSV.
- This report is therefore suitable for later task design and review, while keeping the blind scoring step separated from source metadata.
