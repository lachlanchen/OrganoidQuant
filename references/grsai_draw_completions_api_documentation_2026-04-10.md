# GRSAI Draw Completions API Documentation

Date: 2026-04-10

## Hosts
- Global host: `https://grsaiapi.com`
- China host: `https://grsai.dakka.com.cn`

## Usage
Use `Host + Path`.

Example:
- `https://grsaiapi.com/v1/draw/completions`

## Image Generation API
- Method: `POST`
- Path: `/v1/draw/completions`

Full global URL:
- `https://grsaiapi.com/v1/draw/completions`

Full China URL:
- `https://grsai.dakka.com.cn/v1/draw/completions`

## Get Result API
- Method: `POST`
- Path: `/v1/draw/result`

Full global URL:
- `https://grsaiapi.com/v1/draw/result`

Full China URL:
- `https://grsai.dakka.com.cn/v1/draw/result`
