# DEO Experiment Design Notes

## Purpose
This folder consolidates the experimental logic behind the DEO datasets by combining four source types:
- thesis text and chapter figures
- figure export files used for manuscript-style panels
- meeting/transcription notes that explain intent and interpretation
- a concise handwritten note that summarizes the three main experiment branches

## File Map
- `01_thesis_deo_chapter_notes.md`: thesis-derived scientific claims, experiment logic, and figure mapping.
- `02_transcription_notes_1.md`: interpretation notes from the first transcript.
- `03_transcription_notes_2.md`: experiment-to-figure mapping and why specific days were selected.
- `04_handwritten_experiment_note.md`: concise manual summary of the three major experiments.
- `05_figure2_density_design.md`: design logic for the density figure.
- `06_figure3_alginate_design.md`: design logic for the alginate figure.
- `07_figure5_y27632_design.md`: design logic for the Y-27632 figure.
- `08_figure_style_expectation.md`: expected publication-style figure conventions inferred from the reference image.
- `09_comprehensive_experiment_design_and_quantification_plan.md`: integrated understanding and step-by-step quantification plan.
